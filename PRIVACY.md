# ZAVIX Remote client privacy information

Maintainer: LINVIX SOFTWARES LTDA. Contact: robson@linvix.com.br.

ZAVIX Remote is an assisted remote-support client derived from RustDesk OSS. Opening this preconfigured Windows client contacts the ZAVIX Remote infrastructure to establish availability. Connection identifiers, network addresses and technical device information are used for routing and operation. The configured infrastructure is identified on the project's download page and public privacy page.

In the published assisted profile, the client approves an incoming support request on the computer. During an accepted connection, the technician may view the display and operate input according to the enabled permissions. Clipboard and file transfer are controlled by application permissions. The client provides controls to end the current support connection. No shared permanent password is embedded in the distributed client.

The support gateway participates in the connection and can view transmitted content. The portal records operator and attendance lifecycle information. Recording is disabled by default; when enabled, the current operational retention for recordings is seven days. The operator must discuss recording before sensitive information is shared.

Application diagnostics may be written locally. The exact retention of other server and audit data has not been specified by these operational notes and should be confirmed with the maintainer. These notes do not claim that the current client cryptographically restricts all connections to portal-authorized requests; that agent feature remains a separate implementation stage.

The download page explains the preconfigured support workflow. The MSI installation presents privacy and license information, including the network destination and service installation. ZAVIX Remote and Linvix Remote 1.5.0.3 installers are published; both use the same assisted infrastructure.
